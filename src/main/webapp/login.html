EIS ERP Login

เข้าสู่ระบบด้วยข้อมูลจากตาราง [EIS_ERP].[dbo].[users]

usernameใช้กรอก Username
emailใช้ login แทน Username ได้
password_hashตรวจรหัสผ่านที่ backend เท่านั้น
activeต้องเป็น 1 ถึงเข้าใช้งานได้
lockedถ้าเป็น 1 จะถูกปฏิเสธ login
login_fail_countนับจำนวนครั้งที่ใส่รหัสผิด

Sign in

ระบบจริงควรส่ง username/password ไปที่ Spring Boot API แล้วให้ backend ตรวจ hash กับ MSSQL

Demo user: admin / Admin@1234
ไม่สามารถดูรหัสเดิมจากฐานข้อมูลได้ เพราะเก็บเป็น password_hash ให้ admin reset ด้วยไฟล์ src/main/webapp/sql/reset_admin_password.sql

API contract: POST /api/auth/login

Response ควรคืน token, user_id, username, full_name, active, locked
